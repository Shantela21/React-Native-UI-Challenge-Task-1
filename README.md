A modern **React Native mobile application** built using Expo Router and the latest React Native ecosystem. This project is structured for scalability and performance, making it ideal for learning or production-ready apps.

## Features
⚡ Built with Expo SDK 54
🧭 Navigation using Expo Router
📱 Cross-platform support (Android, iOS, Web)
🎨 Vector icons with @expo/vector-icons
🔄 Smooth animations via react-native-reanimated
📦 TypeScript support with strict mode enabled
🌍 Responsive design with safe area handling

## Tech Stack

## Installation
1. Clone the repository:
```
git clone https://github.com/Shantela21/react-native-task-1.git
```
```
cd react-native-task-1
```
2. Install dependencies:
```
npm install
```
## Running the App

Start the development server:
```
npm run start
```
Run on specific platforms:
```
npm run android   # Android emulator/device
npm run ios       # iOS simulator (Mac only)
npm run web       # Web browser
```

## Reset Project

If you encounter issues, reset the project:
```
npm run reset-project
```
